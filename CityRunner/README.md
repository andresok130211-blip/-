# CityRunner — симулятор жизни на Android (Unity)

План игры: детсад → школа → техникум → работа на выбор → пенсия. Сейчас готов **детализированный город ~1,9 × 1,9 км**
с местами для всех этапов жизни; сами этапы и механики — следующий шаг.

## Что внутри
- Здания-локации **полые**: вход, вестибюль со стойкой, коридор, комнаты с мебелью (классы, палаты, операционная, камеры, кухни, цеха, залы магазинов), свет включается, когда заходишь внутрь. Доступен первый этаж (верхние этажи пока закрыты).
- Рабочие места (`Poi.stations`): парты, кассы, станки, столы врачей и т. д. — основа для будущих профессий.
- Улицы: светофоры, остановки, урны, гидранты, люки, кромки дорог, переходы, фонари, припаркованные машины.
- Окраины: частные дома со скатными крышами, заборами, садами; в центре — витрины, карнизы, балконы.

## Места в городе (Tab / кнопка «Следующее» — выбрать цель, внизу стрелка и расстояние)
Дом, Детский сад, Школа, Техникум, Больница, Полиция, Торговый центр, Продуктовый, Кафе, Банк, Почта, Пожарная часть, Завод, Бизнес-центр, Дом престарелых.

## Android
Меню **CityRunner → Собрать APK** (нужен Android Build Support в Unity Hub). Управление: левый джойстик — ходьба, свайп справа — камера, кнопки «прыжок» и «бег».

# Описание города

Процедурно сгенерированный город (~1 км × 1 км): небоскрёбы с окнами, кирпичные и каменные дома, парки с прудами,
центральная площадь, улицы с разметкой, фонари, деревья и припаркованные машины. По городу можно бегать человечком
от третьего лица. Есть смена дня и ночи (ночью горят окна и фонари).

Все текстуры и модели создаются кодом — внешних ассетов не нужно.

## Запуск
1. Unity 2022.3 LTS или новее (Built-in Render Pipeline).
2. Unity Hub → Add → выбрать папку проекта.
3. Открыть `Assets/Scenes/Main.unity` и нажать Play.

## Управление (ПК)
| Клавиша | Действие |
|---|---|
| WASD | ходьба |
| Shift | бег |
| Пробел | прыжок |
| Мышь / колесо | камера / зум |
| T | +3 часа времени |
| Y | пауза времени |
| Esc | освободить курсор |
| F1 | скрыть подсказки |

## Структура
- `GameBootstrap` — сам собирает игру при старте сцены
- `CityGenerator` — улицы, кварталы, здания, парки
- `CityBatcher` — слияние геометрии в крупные меши (мало draw call'ов)
- `ProceduralTextures`, `CityMaterials` — PBR-материалы
- `PlayerController`, `ThirdPersonCamera` — персонаж и камера
- `DayNightCycle` — солнце, луна, небо, туман

## Идеи для развития
URP + Post Processing (bloom, SSAO), трафик и пешеходы, интерьеры, импорт реальных 3D-моделей, оптимизация LOD.
